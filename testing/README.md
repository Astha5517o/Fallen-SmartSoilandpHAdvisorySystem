# Testing and Calibration

No physical test results are recorded yet. Add entries only after tests have actually been performed.

## Test log template

For each test, record:

- Date and test ID
- Sensor and controller model
- Soil type and sample/container
- Sensor placement and depth
- Condition/preparation of soil
- Power supply and wiring revision
- Raw readings (include units only if they are genuinely known)
- Number of repeats and observed variation
- Interpretation and limitations
- Unexpected behaviour or failures
- Photos or supporting files

## Calibration plan (to be completed)

1. Define repeatable soil conditions and document how each is prepared.
2. Take multiple readings per condition.
3. Record raw values before choosing thresholds.
4. Repeat measurements to see whether readings are consistent.
5. Choose and justify a simple threshold only after reviewing the data.
6. Re-test the threshold with samples not used to choose it.
7. Record limitations; do not report exact moisture percentages unless a validated method supports them.
