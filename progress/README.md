# Progress journal 🌱

This folder is for my own dated notes about what I actually did, what I understood, what went wrong, and what I want to try next.

I want the journal to sound like me, not like a perfect report. It is okay to write simply, use first person, and admit when I am confused. I should not add tests or achievements that I haven't done.

## Suggested format

For each work session, make a file named `YYYY-MM-DD.md` and answer a few of these in my own words:

- What did I work on today?
- What did I draw, read, compare or change?
- What do I understand better now?
- What is still confusing or not verified?
- What did I not finish?
- What is the next small step?

The journal template in `2026-11-01-journal-prompts.md` is a set of prompts, not a finished journal entry. I should write the actual entry myself, using my real experience.
